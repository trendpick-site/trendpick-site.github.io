개인정보처리방침

안내: 현재 공개 테스트 버전 기준의 기본 안내입니다. 광고, 방문자 분석, 문의 양식 등을 추가하기 전에 실제 운영 방식에 맞춰 수정해야 합니다.

1. 사이트에서 직접 수집하는 정보

현재 트렌드픽의 자체 홈페이지는 회원가입, 로그인, 문의 입력 양식을 제공하지 않으며 이용자가 직접 입력하는 개인정보를 자체 서버에 저장하지 않습니다. 검색어 필터 입력값은 브라우저에서 목록을 걸러보는 데 사용됩니다.

2. 외부 호스팅 및 링크

사이트는 GitHub Pages를 통해 제공됩니다. 호스팅 제공자가 서비스 운영과 보안을 위해 접속 관련 정보를 처리할 수 있습니다. 외부 검색·기사 링크를 클릭하면 해당 서비스의 개인정보처리방침이 적용됩니다.

3. 쿠키 및 광고

현재 이 버전에는 트렌드픽이 직접 설치한 광고 추적 코드나 자체 분석 도구가 포함되어 있지 않습니다. 향후 광고 또는 분석 기능을 도입하면 관련 처리 내용과 선택권을 안내하겠습니다.

4. 문의

문의 채널은 문의 페이지를 참고하세요. 실제 운영자 연락처가 준비되기 전에는 개인정보를 보내지 마세요.
